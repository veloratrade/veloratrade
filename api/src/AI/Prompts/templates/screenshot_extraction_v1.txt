Extract trade data from the image and return ONLY valid JSON.

Required JSON fields (use null if not visible):
{
  "symbol": "e.g. XAUUSD, EURUSD, BTCUSD",
  "side": "buy or sell",
  "entry": "entry price as string, e.g. 2000.50",
  "exit": "exit price",
  "lot": "lot size / volume",
  "sl": "stop loss",
  "tp": "take profit",
  "pnl": "profit/loss, e.g. 150.25 or -20.5",
  "openTime": "YYYY-MM-DDTHH:MM or YYYY.MM.DD HH:MM:SS",

- Return ONLY JSON, no markdown, no explanation.
- Prices must be numeric strings, no currency symbols.

- Confidence: 0.9 if all fields clear, 0.7 if partial, 0.4 if uncertain.
